# 模块52：位移控制摩擦基准并迁移负例（2026-11-03）

依据 `analysis/装配仿真验收提速调研_2026-11-03.md` §3：把「长时间不收敛」的滑移
负例改为**有数值答案的位移控制滑块试验**——迁移前先完成等价覆盖审核（本文件
§覆盖迁移审核），原负例**不删**，保留为显式慢测试开关；超时/取消/崩溃等软件行为
改用可控注入进程秒级验证。

## 位移控制滑块基准（verify/friction_benchmark.py）

- **法向夹紧力可核对**：上块顶面 5MPa 均布压力 → 名义 N=5MPa×400mm²=2000N；
  无重力 → 底面 ΣRFy 解析精确（实测两网格差 ≤7.3e-10，判据 ±1%）。
- **非测试方向刚体自由度限制**：下块底面全固定；驱动侧面（PART2_SIDE, x=20）
  节点 u_z≡0（面外）+ u_x=d（测试方向，整面同值=刚性压板理想化）；法向由
  接触+压力持有。deck 注入路径与接触门步骤⑤预定位移同款（*BOUNDARY 注入），
  另注入驱动面 *NODE PRINT RF（平衡核对需要）。
- **逐步切向位移**：位移程序 d=(1e-4, 5e-4, 3e-3, 2e-2, 0.1, 0.25) mm（几何级数
  跨 3.5 量级），每个位移点独立单步求解（ccx 步内自动增量 0→d 斜坡）；摩擦平台
  与滑移历史无关（库仑），分点求解与连续增量等价（口径记录于此）。
- **μ=0.1 与 0.3 两档 × 网格 {2,4}mm 两档**（判别力双网格验证），同一调度器
  并发 2（make_scheduler，分级预算，[memory] 行照常打印）。

## 超时/取消/崩溃的秒级注入（调研§3 末段；验收标准⑥）

C# 夹具 scheduler_probe（模块46 同款，非求解器证据）注入 SolveScheduler：
- **超时**：stall_at_cap 挂起 → wait_task 4s 超时 → cancel → STATE_CANCELLED +
  stop_reason=cancelled（秒级）；
- **取消**：提交即 cancel（排队/运行）→ STATE_CANCELLED 秒级终态；
- **崩溃**：未知作业名 → 夹具 exit 23 → STATE_FAILED +『日志无 Job finished』分类；
全程 <60s（对比：原负例每个滑移证据点需 300s 等待窗）。内存预算分类
（memory_limit / memory_limit_near_exit）已由模块46 ①注入门承载，不重复。

## 覆盖迁移审核（调研§3 第 5 点：等价覆盖审核通过后才迁移）

**被迁移门**：verify_contact_friction_connection.py 步骤 A④ 的 μ=0.1 分支——
载荷控制负例（夹紧 5MPa→N=2000N + 侧向 300N 载荷，μ=0.1 → μN=200<300）：
滑移=刚体自由度不闭合 → ccx 长时间不收敛 → 300s 超时取消 =「滑移证据」
（双结局门：任务失败/超时取消 或 u_x>0.01mm；module_46 编排提速为预置提交）。

| 维度 | 原负例（载荷控制 300s） | 新基准（位移控制） | 等价/更强？ |
|---|---|---|---|
| μ=0.1 滑移判别 | 间接否定证据（不收敛/超时，调研§3：不能排除内存保护/非法输入/引擎故障） | 正向测量：平台 F_t/N=0.0994≈μ±15% | **更强**（直接物理量+排除歧义） |
| μ=0.3 判别 | 粘着 u_x≤3e-3mm 门（保留在步骤 A④ 不变） | 平台 F_t/N=0.3000±15% | 更强（增加定量平台） |
| 两档可区分 | 仅「一个收敛一个不收敛」的定性对比 | 平台比 3.00，±15% 区间不交 | 更强 |
| 网格判别力 | 无（单网格 2mm） | 两网格 {2,4}mm 结论一致 | 更强 |
| 粘着阶段 | 侧向 100N 工况（步骤 A③ 保留） | 基准内 F_t/N<0.7μ 点 | 等价 |
| 平衡 | 步骤①③ RF 门（保留） | 基准逐点底面+驱动面 ΣRFx 平衡 ≤0.5% | 更强 |

**审核结论**：新基准覆盖原负例的全部判别意图（μ=0.1 滑移、两档可区分）并在
正向测量、双网格、定量平台、逐点平衡/接触证据上更强；原负例独有的「真实引擎
长时间不收敛路径」保留在慢开关中可复跑。**审核通过，准予迁移**。迁移后步骤 A④
= μ=0.3 粘着门（保留）+ 默认档基准；**原负例不删**，由
`RM_SIM_FRICTION_SLOW_NEGATIVE=1` 显式启用（预置提交/300s deadline/双结局门
语义原样）。
