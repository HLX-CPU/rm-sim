# 绑定预处理、节点位置与求解错误

新建粘接和简化销轴连接默认 `adjust_nodes=False`，输出明确的
`ADJUST=NO`，保留输入网格坐标。勾选设置对话框的“绑定节点调整”才输出
`ADJUST=YES`。保留坐标不会自动弥补间隙或漏绑，连接覆盖仍须检查。

旧工程缺少此字段时按过去的求解器默认值迁移为 `True`，保存后写明字段；
不会静默改变旧工程定义。连接列表、报告连接参数及实际 INP 均记录此策略。

自动草稿对同一对零件采用同一从件：面积最大的公共补丁提供原推荐方向，
其余补丁统一方向。缓存的旧草稿应用时也执行此规则，保留原行顺序和索引。
手工连接和已经保存的连接对象不会自动换向。

求解文件把同一主从件及同一调整策略下的所有粘接/销轴补丁合为一个 TIE，
并集保留每个补丁的全部网格面、去除重复网格面；不会只保留最大面。
每个连接原来的 Cn 面集仍保留，供逐连接诊断和应力积分使用。
不同部件对、不同调整策略以及可分离接触、螺栓、共节点连接不混合。
此规则解决同一对零件的重复依赖；多件环路或其他约束冲突仍需单独检查。

草稿窗口按面积排序只改变显示，勾选和类型覆盖映射回原始候选索引，
避免把用户修改施加到另一处连接。

求解成败必须同时满足：完整日志无 ERROR、出现 `Job finished`、结果解析成功。
日志检查分块读取，保留 ERROR 总数、少量行号及上下文和完整日志哈希。
即使错误已经离开内存中的末尾摘要，或求解器修补系数后继续结束，也拒绝结果。
未绑定节点警告仍按实际节点集合统计并提示检查，不能因无 ERROR 就判连接合格。

验证入口：`verify/verify_tie_policy.py`、`verify/verify_scheduler_lifecycle.py`、
`verify/verify_assembly_solve.py`。证据与限制见
`analysis/绑定预处理_修复与验证_2026-11-02.md`。

依据：[CalculiX 2.22 手册 *TIE，第613–614页](https://www.dhondt.de/ccx_2.22.pdf)。
从面节点默认投影调整；从节点不能重复用作其他 SPC/MPC 的依赖节点。
FRD 坐标比较计入先转 float32 再以 `%12.5E` 输出的精度，来源为
[官方 frd.c](https://github.com/Dhondtguido/CalculiX/blob/master/src/frd.c)。
