# 模块25：运动载荷到结构静力的最小链路

`solver/chrono_adapter.py::transfer_load` 从真实Chrono弹簧场景选取一个时刻的世界力向量，
记录源JSON的SHA256、时刻、源力与显式3×3旋转矩阵，将Chrono -X映射为结构梁 -Y。
两端均使用N，长度单位m→mm不对力额外乘1000。映射力作用于标准梁x最大端面。

`verify_chrono_load_transfer.py`先跑真实动力学，再经 `main.py --batch`执行映射与有限元。
独立读取DAT核对RF+F残差<0.01N，并按100mm梁解析位移核对≤2%。
实测选取载荷约99.88N，端部Uy约-0.190265mm。
完整来源、映射、原始有限元输入、日志和结果均保留。

统一入口：「运动→运动载荷→梁静力示例」。当前为单向、单时刻准静态传递，
不声称实现瞬态载荷历史、空间分布载荷、双向耦合、跌落冲击应力或塑性损伤。
