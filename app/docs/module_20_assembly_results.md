# 模块20：装配与单部件结果

本轮已接通真实主窗口求解和结果回收，而非只用手写数据构建对话框。

- `solver/assembly_workflow.py`：零件/装配共用准备、求解输入、场回收、归档和 case 索引。
- `solver/fields.py::field_surface`：裁剪部件全部节点（包括二阶中点）及其体单元边界，局部极值不再取整个装配。
- `gui/main_window.py`：真实分部件材料、约束载荷、连接、求解、结果菜单与报告。
- `gui/setup_dialog.py`：材料、面力/压力/力矩/重力、固定、粘接、接触摩擦、简化螺栓和销轴定义。
- `mesh/mesher.py`：用 CAD 面所属网格节点，避免相邻部件重合边线混入固定集；兼容曲面。
- 界面表显示两侧应力外推积分的力向量、法向压应力积分，明确为近似量；不把混有 MPC 力的 FORC 合力冒充纯接触力。

验证：`verify_gui_assembly.py` 经 Qt 表单信号→真实主窗口求解→实际部件选择与局部 PNG；
`verify_face_ownership.py` 核对贴合界面两侧节点互不混入；`verify_assembly_results.py`
核对已有场数据、连续性、合成场与 PNG 标注。

## 原应力门的边界

旧脚本把「仅排除界面1×MeshSize后的节点最大Mises≈10MPa」改成了界面6×MeshSize、
两端5×MeshSize且排除表面节点。**该原始最大值门未获得通过，不能用远场 PASS 替代。**
新日志保留原范围最大值诊断；既有远场门仅证明明确统计区域中的近似轴应力。

理论10MPa是均匀单轴应力，不覆盖全固定端、点状等效节点力引入或钢铝界面泊松收缩
失配的局部峰值。CalculiX 的 FRD 应力是从积分点外推到节点的数据，不能当作无误差的解析点值。
参考[CalculiX官方手册](https://www.dhondt.de/ccx_2.13.pdf)。

新增 `verify_assembly_patch.py` 提供独立、全节点、不排除区域的解析补丁：假设材料A/B
的 ν/E相同、均匀轴压、允许横向收缩，理论 Mises=10MPa；所有节点±1%、端位移±0.1%、
反力0.01N门通过。它明确使用假设材料和不同边界，不伪称满足真实钢铝全固定算例的原局部最大值门。
