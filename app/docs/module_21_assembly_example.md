# 模块21：两件式装配端到端示例

`main.py --batch examples/assembly_contact.json` 经导入→分部件材料→接触摩擦→网格→
求解→结果→报告→工程束。两叠块20×20×20mm、Q235、底面固定、顶面1000N向下及自重。

`verify/verify_assembly_example.py` 在两个独立批处理进程中分别计算接触μ=0.3与粘接对照，
直接读取 INP/DAT/FRD/VTU，独立积分网格体积和界面应力，而非只核对产品返回的摘要。

实测接触RFy=1001.221333586N；CAD/角点网格体积自重理论总量1001.232136N，误差约0.0011%。
下侧界面法向压应力积分1000.605736N，接触不出现拉区；粘接对照反力差远小于0.1%。
报告列出每部件材料、连接参数与假设、两侧界面力。

原始产物持久保留在 `E:/rm_sim/verification/assembly_example_*`；最终可打开的示例工程
位于 `examples/assembly_contact/project.rmsimproject`。

旧 `verify_assembly_solve` 的接触卡族验收曾复用粘接的偏心侧面载荷，修正面节点归属后
暴露出倾覆/不收敛。本轮将该**卡族成功求解算例**改为底面固定、顶部均匀轴压；仍要求真实
求解成功，失败记录保留。分离/摩擦/滑移的物理判别仍由独立接触脚本覆盖。
