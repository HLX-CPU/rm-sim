# 绑定带：按实测几何挑出真正能绑上的从面节点

模块 31（2026-11-02 实测定型）。入口 `solver/bond_band.py`，接入
`solver/deck.py::_connection_cards / tie_group_cards`；验证入口
`verify/verify_bond_band.py`。

## 问题：警告数量反映的是「CAD 面比贴合区大多少」

CalculiX `*TIE` 逐个从面节点投影到主面：只有「投影落在某个主面片内、且法向
距离不超过 `POSITION TOLERANCE`」的节点才生成 tied MPC，否则写
`WarnNodeMissTiedContact`：

```
*WARNING in gentiedmpc: no tied MPC
        found; in-face tolerance:    4.6444798689638028E-003
```

实测（20 实体快拆整装，4 mm/curvature12/min0.4，133810 单元）是两个来源叠加：

1. **两个独立划分曲面之间的离散差**：销-基体从面节点到主面 0.004—0.012 mm
   （中位 0.0173、p90 0.0511），而求解器默认搜索半径只有 0.004024 mm
   （约 1e-3×典型单元尺寸）——本可绑上的节点被判 `too far`。
2. **CAD 面远大于贴合区**：端片-壳体面 666 个从面节点里 285 个间距为 0，
   其余 0.345—10.1 mm。把容差放大到覆盖整张面就会跨过真实配合间隙
   （单边 0.345 mm）去绑，属于过度约束。

整装 39 条连接合计 17194 个从面节点，其中 12437 个（72.3%）落在对方贴合区内，
4757 个（27.7%）在外（销端面外伸 0.19—0.32 mm、轴承面 1.45—1.54 mm、
端片-壳体 2.7—10.1 mm）。最终求解里仍有 28 个节点未绑定（10319 个绑定从面节点的
0.27%），逐连接归因见整装报告。

## 做法：从面写节点集，不写整张面

* 逐从面节点计算「到主面的最近投影」；只有投影落在主面片内部、且距离 ≤ 带宽
  的节点才写进 `*SURFACE, NAME=…, TYPE=NODE`。
* `*TIE` 的 `POSITION TOLERANCE` 统一 **0.07 mm**（实测上下界重合）。
  再小会多留 `too_far`（整装 0.0163/0.03/0.05 → 56/47/35 个）；再大（0.1）会让
  共面贴合面的 tie 搜索退化（同一 1 mm 杆模型 20 s → >10 min；0.07 及以下
  15—23 s）。0.07 是最小真实间隙 0.345 mm 的 20%，不会跨间隙绑死。
  `ADJUST=NO` 不移动任何坐标。
* 主面保持整张 CAD 面的单元面（远离的节点本来就搜不到，保留整张面最稳）。
* 同一部件对的多个补丁合并为一个 TIE：从面是**节点并集**，主面是**单元面并集**。
* 求解文件逐连接记一行 `** 绑定带「名称」…：从面 A N 节点里 M 个投影进主面并
  参与绑定（最大间距 …），其余 K 个在贴合区外、不参与绑定（到主面最近 …）`。
  贴合区外的节点**不进入从面**，因此不会产生 no_face/too_far 警告；但这条注释
  就是「整张 CAD 面里有多少没贴合」的凭据，不能当成全贴合。
* 没有一个节点能投影进主面 → `DeckError` 显式拒绝（「这不是贴合连接」）。
* `band=0` 显式回到旧行为：整张 CAD 面的单元面 + 求解器默认搜索半径。

为什么不用「面片级裁剪」：面片是能改的最小单位，而贴合区边界常落在面片内部。
按「面片全部节点都能投影」裁会连贴合区内部节点一起裁掉（整装实测销螺纹面只保住
约 38% 可绑节点，等于把绑定面积缩水）；按「面片至少一个节点能投影」裁又几乎不裁
（5672/6000 面片），警告仍有约 3633。节点级从面正好只绑定真正落在贴合区的节点。

依据：`*TIE` 从面可以写成节点集（`*SURFACE, TYPE=NODE`）。实测
`E:\rm_sim\verification\node_tie_probe_20261102_1902`：同一 deck 换成节点从面后
未绑定 0、`ΣRF=(0,0,99.99999983) N`、`|U|max=0.0026 mm`（对照：整张面旧行为
387 个未绑定）。

## 验证（真实 CCX）

`verify/verify_bond_band.py`：

| 组 | 场景 | 结果 |
|---|---|---|
| A | 两面留 0.05 mm 间隙，band 0.1 | `TYPE=NODE` + `POSITION TOLERANCE=0.055`（按实测间距）；未绑定 0；ΣRF=(0,0,100.0000018) N；坐标未被移动；\|U\|=0.0022 mm |
| B | 同几何 band 0.02 < 间隙 | 生成求解文件即显式拒绝（从面 79 节点无一个可投影） |
| C | 整张从面（453 节点）只局部贴合 | 只把 66 个贴合节点写进从面（其余 387 个在 5.8—14.1 mm 外），容差 0.07；未绑定 0；ΣRF≈100 N |
| D | 同 C 但 band=0（旧行为） | 未绑定 387 → 节点级裁剪没有削弱诊断门 |
| E | 纯几何：贴合区小于一个面片 | 4 个从面节点里只保留 1 个（另 3 个在区外） |
| F | 纯几何：完全不重叠 | 可绑节点 0（deck 层显式拒绝） |

## 限制

* 带宽是**几何**判据，不是接触或可分离模型；绑定区仍按「焊死」传力。
* 贴合区外的节点完全不参与绑定：这比「整张面都绑」更接近真实贴合，但也意味着
  27.6% 的从面节点没有建模贡献；这些节点逐连接记录，供判断是否需要改接触模型。
* 节点级从面对弯曲主面的投影方向依赖求解器实现：整装 235908 节点实测 0 警告、
  反力平衡（见整装求解报告）；不同网格配方仍需复核警告数。
* 主从方向仍由自动草稿按「同部件对最大公共补丁」统一决定，不为单个小补丁反向。
* 不证明强度；材料状态、屈服强度与安装夹紧细节仍未确认。
