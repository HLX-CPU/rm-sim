# 连接物理假设与适用范围（权威文档）

本文档是连接数据模型（`core/connections.py`：ConnectionBase + 四类连接）的
**物理假设权威来源**：每类连接四节——物理假设 / 适用范围 / 不模拟项 /
验证算例指针。求解实现（绑定/接触/预紧的 CalculiX 语义转换）属后续模块；
本文档的假设必须随连接实例的计算结果一起呈现给用户（调研报告 §7：
建模解释的真实程度须经连接假设与实验评估）。

通用约定（四类连接共用）：

- 连接引用**两部件的面指纹对**（side_a/side_b 各为 (part_id, FaceFingerprint)）；
  同一部件自身连接、引用不存在的 part_id 均被校验拒绝（`ConnectionBase.validate`）。
- 面指纹跨会话身份（gmsh 不承诺 occ 编号不变）；重开工程按指纹在部件面清单内
  re-resolve（模块 14 机制），不唯一命中 → 「需重新确认」。
- 语义关系：模块 14 的 `Constraint(kind="bonded")` 是工况树上的轻量内部连接
  声明（不接地、暂不参与求解）；本体系的连接对象携带参数与本文档假设，
  是后续求解模块的结构化输入。
- 预留类型位：弹性连接（elastic，分布式耦合/弹性支撑）**本期有意推迟**——
  四类连接落地并验证后，再按调研报告 §4「销轴、分布耦合、弹性支撑」扩展。
- 新建粘接/销轴默认保留网格节点坐标（`adjust_nodes=False`，`ADJUST=NO`）；
  旧工程缺字段时迁移为旧行为 `True`。同一主从件的补丁在求解时取网格面并集，
  不丢补丁。详见 [绑定预处理](module_30_tie_preprocessing.md)。
- 绑定默认按实测几何挑从面节点（绑定带 0.1 mm）：只有投影落在主面内、法向距离
  ≤带宽的节点写进 `*SURFACE, TYPE=NODE`，`*TIE` 写 `POSITION TOLERANCE=0.1`；
  逐连接记录从面总节点数、可绑节点数与贴合区外节点的最近距离。
  详见 [绑定带](module_31_bond_band.md)。

## 粘接（BondedConnection）

**物理假设**

- 假设 1（全绑定）：两侧面全部节点三向位移一致——无相对滑移、无分离，
  界面等价于刚性一体（理想绑定）。
- 假设 2（无粘接层柔度）：胶层/焊缝的厚度与材料弹性被忽略，面-面直接
  绑定，界面不引入额外柔度（界面刚度 = 无穷大理想化）。
- 假设 3（界面强度无限）：界面永不发生开裂/脱粘，粘接强度不进入计算
  （结果解读时不得把界面应力当作胶层应力）。
- 假设 4（线弹性范围）：被连接件材料线弹性、小变形——本连接的全部
  门限与结论仅在线弹性范围内有效（超弹性/塑性须重新评估）。

**适用范围**

- 装配体中「焊死/满焊/螺栓群充分夹紧可视为一体」的连接面的刚度级分析；
- 关心整体刚度/位移/远离界面区域的应力，而非界面局部强度的场景。

**不模拟项**

- 胶层厚度、胶材料弹性与粘弹性行为；
- 界面开裂、脱粘、疲劳与强度校核；
- 表面处理、粗糙度、配合公差对界面刚度的影响。

**验证算例指针**

- **串联双杆粘接算例（模块 17，已实现）**：`verify/verify_bonded_connection.py`
  ——杆1 钢 E=210000、杆2 铝 E=70000（各 10×10×100mm，x=100 界面粘接，
  固定 x=0、自由端 +x 拉 1000N；几何样例 `samples/assembly_serial_rods.step`，
  生成器 `cad/make_assembly_samples.py::make_serial_rods_step`）。
  **门限**：端部 Ux vs 串联理论 δ=FL/(E1A)+FL/(E2A)=0.0190476mm 误差≤2%
  （判别力：杆2 误配为钢 → δ=0.0095238mm≈1/2，被门咬——同时证明 per-part
  材料正确；「断带 4× 数字」仅在杆2 被意外约束时成立，不作求解级门）；
  ΣRF=1000N（相对 0.01%）；粘接界面从面侧节点力合力=1000N±1%（经从面
  应力积分 σxx·A——ccx RF/FORC 不含 *TIE MPC 力，实证 ±5.4N 残差）；
  界面两侧轴向应力（SXX）面均值差≤15%（Mises 受从面约束剪切扰动——
  首跑标定豁免：实测 Mises 差 37.6%，SXX 差 1.4%，单轴态 Mises=|σxx|）；
  MeshSize 2mm vs 1mm 的 δ 差≤1%；断带负例：去 *TIE → 杆2 悬浮 →
  **装配连接性门**（deck 层）显式拒绝——ccx 2.22 对该奇异体系仍输出
  'Job finished' 但 Ux≈-8.6e10 mm 垃圾解（实证），deck 层拒绝比垃圾结果
  交给用户安全。
- `probes/beamCheck.json` + `verify/verify_static_solve.py`：绑定体（梁）
  求解基线（挠度/反力门，后续 *TIE 实现须复现同基线）。

## 可分离接触+摩擦（ContactFrictionConnection）

**物理假设**

- 假设 1（法向可分离）：界面只能传压力不能传拉力——张开（分离）后法向
  力为零；接触状态由求解器逐迭代判定。
- 假设 2（Coulomb 恒定摩擦）：切向力满足 |τ| ≤ μ·p，μ 为常数（各向同性、
  不随压力/速度/温度变化）；钢-钢干摩擦典型 μ=0.3（文献范围 0.15~0.5 取中值，
  模板默认，可实例化覆盖）。
- 假设 3（小滑移）：接触面配对在分析过程中固定（小滑移公式化），不考虑
  滑移路径对几何的更新。
- 假设 4（罚刚度依赖）：接触压力-闭合关系为**线性罚格式**（*SURFACE
  BEHAVIOR PRESSURE-OVERCLOSURE=LINEAR）——传力精度/侵入量依赖罚刚度
  标定（模块 18：1000→1e6 MPa/mm，间隙闭合反力实测 42423.76N vs 理论
  42000N）；粘着切向亦为罚弹性（stick slope），粘着位移含切向罚柔量。

**适用范围**

- 可分离/可滑移的装配界面：支承面、搭接面（螺栓预紧后仍可能有微滑移的
  场景按详细螺接处理，见 §螺栓）、销孔外的面-面接触；
- 关心接触压力分布、滑移起始、分离区域的场景。

**不模拟项**

- 大滑移与滑移路径历史效应；
- μ 随法向压力/滑动速度/温度的变化，润滑、磨损、黏着；
- 接触面粗糙度与真实接触面积统计效应；
- 塑性压痕（接触应力超过局部屈服时几何/表面损伤不进入计算）。

**验证算例指针**

- **装配接触算例（模块 18，已实现）**：`verify/verify_contact_friction_connection.py`
  ——两叠块 20×20×20（下块底面固定；几何样例 assembly_two_blocks；可分离性
  子算例用 0.1mm 间隙几何）。**门限与实测**：
  ① 压缩 1000N −y：ΣRFy=1000N（≤0.1N，实测 999.999994）；界面法向压力
  积分（从面 σyy·A 求和）=1000N±10%，压力场 ≥0（只传压不传拉）；
  ② 仅重力：ΣRFy=2ρV_mesh·g=1.2213N（±1%；V_mesh=网格四面体实际体积
  16000mm³，模块 7 实测网格/CAD 体积差量级）；上块自重经界面入地基；
  ③ 夹紧 5MPa（N=2000N）+侧向 100N<μN=600N：ΣRFx=−100N、ΣRFy=2000N
  （≤0.1N）、顶块粘着 u_x=4.09e-4mm≤1e-3mm（粘着理论 F·h/(G·A)=1.238e-4，
  切向罚柔量 3.3×——首跑标定）；
  ④ μ 判别对（侧向 300N）：μ=0.3 粘着 u_x=1.23e-3mm≤3e-3（=1e-3×300/100，
  随载荷线性标定）；μ=0.1（μN=200<300）滑移——实测**未在 300s 内收敛**
  （持续滑移=刚体自由度，超时取消）——证伪「μ 数值不可区分」；
  ⑤ 可分离性（预定位移法，间隙 0.1mm）：下压 0.05mm<间隙 → 底块反力
  0.000000N≤1N（张开不传力）；下压 0.12mm → 反力 42423.76N≈k_series·0.02
  =42000N±10%（k_series=2.1e6 N/mm=两块 EA/L 串联；罚刚度 1e6 标定）；
  ⑥ μ=0 侧向对照：任务 failed（界面切向刚体自由度不闭合——奇异/不收敛，
  如实记录，不做硬门）。
- `verify/verify_assembly_loads.py` ⑤：压力法向语义门（合力 = p·A、纯沿
  法向）——接触法向行为的基础语义（已过）。

## 简化螺栓（BoltConnection）

**物理假设**

- 假设 1（不建螺栓杆实体）：螺栓杆/螺纹/螺母完全不建几何——预紧以
  **耦合区**（垫片等效半径 r 的环带）上的等效力系施加，被连接件经耦合区
  传预紧力 F_p。
- 假设 2（预紧恒定）：预紧力 F_p 在分析全程恒定（一步施加后保持），不模拟
  拧紧过程的非线性、也不模拟工作载荷下的预紧弛豫。
- 假设 3（耦合区压力等效）：法兰面压力分布由耦合区等效力系代替真实
  螺栓头部/垫片接触——耦合区半径默认取公称直径（M8→8mm、M10→10mm）。
- 假设 4（预紧量级）：F_p 默认按 8.8 级 F_p≈0.7·As·σ0.2 估算
  （M8: As=36.6mm² → 16 kN；M10: As=58mm² → 26 kN），模板可覆盖。

**适用范围**

- 以预紧夹紧为主的螺栓连接的整体刚度/位移/被连接件应力分析；
- 螺栓群布置的法兰/搭接连接的载荷分配趋势判断。

**不模拟项**

- 螺栓杆弯曲/剪切刚度、螺纹啮合与螺母滑移、螺栓头部局部接触应力；
- 螺纹松脱、预紧弛豫与疲劳；
- 垫片非线性刚度（若需按详细螺接处理，属调研报告 §4「详细螺接」后续阶段）。

**验证算例指针**

- **装配螺栓算例（模块 19，已实现）**：`verify/verify_bolt_pin_connection.py`
  步骤 A①②——两叠块 20×20×20（下块底面固定；界面=接触；螺栓=耦合区刚体
  连接+预紧力对）。**门限与实测**：① 仅预紧 F_p=2000N → ΣRF_ground 自平衡
  （实测 (0,0,0)，|ΣRFy|≤20N 门=1%×F_p）；界面从面节点力合力（FORC）
  =2000.001N（2000N±10%）；节点法向力 ≥0（最小容差 −1%×F_p 内）。
  ② 预紧+500N 上拉 → 接地反力 ΣRFy=−500.0000N（相对 0.01%）；界面残余
  夹紧 = F_p−外载 = 1500N（平衡闭环理论值；FORC@从面含刚体 MPC 混合力
  1999.999N——首跑记录为非清洁量，不设门）。
- `verify/verify_assembly_loads.py` ⑤：力矩节点力偶守恒门（ΣM·轴精确）——
  预紧等效力系的施加机制与该门同源（本期已过）。

## 简化销轴（PinConnection）

**物理假设**

- 假设 1（零间隙绑定）：销部件柱面与板孔壁面**零间隙绑定**——配合间隙
  被声明忽略，销与孔壁直接绑定传力。
- 假设 2（销为传力路径）：销贯穿多板时为每块板声明一条 PinConnection
  （共用销侧引用，如样例 p3↔p1、p3↔p2）——全部绑定后销成为板间唯一
  传力路径，载荷经销「钉」作用传递。
- 假设 3（销偏刚）：销弯曲/剪切柔度被忽略——销作为刚性传力元件处理，
  孔壁受力偏保守（实际柔度会缓和峰值）。
- 假设 4（无挤压校核）：孔壁挤压（bearing）应力不做校核——销-孔为绑定
  而非接触，孔壁压力分布是绑定反力而非真实挤压分布。

**适用范围**

- 销连接的整体传力路径与被连接板远离孔区域的应力/位移分析；
- 概念/初步设计阶段的销载荷估算（销剪力 = 板间传递力）。

**不模拟项**

- 孔壁挤压（bearing）应力分布与挤压失效校核；
- 配合间隙、微动磨损与微动疲劳；
- 销弯曲/剪切柔度、销的拆装与自锁。

**验证算例指针**

- **装配销轴算例（模块 19，已实现）**：`verify/verify_bolt_pin_connection.py`
  步骤 B③④⑤——几何（评审补齐版）：plate1 x∈[0,60]、y∈[0,20]、z∈[0,5]；
  plate2 x∈[40,100]、y∈[0,20]、z∈[5,10]；两板 (x=50,y=10) Ø8 通孔（z 向
  贯通）；销 r=4、轴心 (50,10)、z∈[0,10]，销面=两板孔壁（零间隙绑定；
  不考虑孔挤压/间隙/销弯曲柔度）。**门限与实测**：③ 两板孔壁面积
  = 2π×4×5=125.66mm²（occ 解析 ±1%，实测 125.6637）；绑定面单元节点全部
  位于 r=4 圆柱面（防无孔埋入圆柱的假实现）；④ 500N 拉过销：求解成功 +
  ΣRF=(−500,0,0)（相对 0.01%）+ 板1 x=40 纯轴段 |Ux|=9.5238e-4mm±10%
  （1mm 网格实测 0.3%；2mm 实测 8.3%）；⑤ 销缺失（无连接）→ 装配连接性门
  DeckError（板2/销悬浮，显式拒绝——ccx 对该奇异体系仍 'Job finished' 但
  位移为垃圾，首跑实证 module_19）。
- **投影实证（module_19）**：销绑定 tie 从面=销全长侧面（全部节点投影成功，
  0 条 "no tied MPC"）；若反用（从面=孔壁）ccx gentiedmpc 对全部孔壁节点
  报 "no tied MPC"（588 条实证）——绑定失效，方向不可反。
- 几何样例 `samples/assembly_lap_pin.step`（销 p3 ↔ 板 p1/p2 孔壁，
  `cad/make_assembly_samples.py` v1 规格，部件身份验证用）；
- `verify/verify_assembly_import.py` ②：双板通孔/销的面清单与部件归属
  （孔壁面可查，本期已过）。

## 连接复核决策闭环（模块47）

自动连接草稿与整装求解的遗留复核欠账（如快拆整装 39 补丁/22 部件对中 28 个
未绑定从面节点）按**逐连接**决策收口——`requires_review` 是布尔汇总、
`untied_nodes`/`reported_missed_nodes` 是节点计数，节点数只作关联证据字段，
不据此自动决策，也不按节点数伪造"已决策"。

- **needs_review 回写**：每次求解后由诊断 coverage 回写——该连接的从面出现
  未绑定节点（`reported_missed_nodes>0`）→ `needs_review=True`（见
  `solver/assembly_workflow.py::finish_analysis`）。
- **未决策拦截**：存在 `needs_review` 且 `review_decision='pending'` 的连接时，
  求解入口（`prepare_analysis`）拒绝并给出中文提示，不静默通过；未出现警告的
  连接不受影响（旧工程缺复核字段按未标记兼容迁移）。
- **决策枚举**（`REVIEW_DECISIONS`，界面标签 `REVIEW_DECISION_LABELS`）：
  `pending`＝「未决策」；`keep_bonded`＝「保留粘接」（复核闭合，求解器警告如仍在，
  呈现为已复核）；`switch_contact`＝「改为可分离接触」（原位替换为
  ContactFrictionConnection，μ 默认 0.3，两侧面指纹对原样保留，绑定警告随
  *TIE 消失）；`remove`＝「删除连接」（从工程删除）。决策落字段
  `review_decision/review_decided_at/review_evidence`，随工程保存。
- **证据展示**：逐连接展示绑定带注释证据（从面总节点/可绑节点/贴合区外个数
  与最近距离——INP「** 绑定带」行）与诊断 coverage 关联节点数（从面节点/
  未绑定/SPC 自由度已固定）；批处理路径 `solver/connection_review.py`，
  GUI 路径「连接复核…」（自动连接草稿对话框入口）。
- **合计口径**：逐连接 `reported_missed_nodes` 合计与检查记录
  （warning_attribution.json/independent_check.json）的 `untied_nodes` 交叉
  核对；SPC 自由度已固定的诊断编号（求解器正常行为）**单列展示**，不与
  未绑定节点混算；检查记录读不到时如实记 `unknown`，不凑数。
- 决策不改变物理假设本身：保留粘接仍是无滑移绑定，改可分离接触即适用
  本文档 §可分离接触+摩擦 的全部假设与限制。
