# SOLIDWORKS 批量标注圆直径验证报告

验证时间为 2026 年 11 月 20 日，版本为 SOLIDWORKS Design Premium 2026 SP0.0（API 34.0.0）。使用临时零件和装配体测试。测试结束时，验证脚本恢复测试前的活动文档和打开文档列表。

## 实机 API 验证

| 用例 | 实测结果 |
| --- | --- |
| 混合草图 | 选中 6 个欠定义整圆，其中 5 个改为 Ø12.5 mm。已有驱动半径的圆提示跳过。固定圆、圆弧、直线和原圆心位置保持原样。 |
| 已有直径和等径关系 | 复用原驱动直径。已有等径的一对圆共用一个驱动标注。共 4 个原生 Ø 驱动尺寸加入同一链接值组。 |
| 后续改值 | 修改链接组内一个驱动直径到 Ø16 mm，5 个目标圆同步更新。保存、关闭并重开测试零件后，5 个直径和链接组仍有效。 |
| 操作中途失败 | 分别在新增第一个尺寸后和批量重建后注入故障，两次均恢复直径、圆心、关联尺寸名称、约束和链接。 |
| 整批撤销 | 调用宏的撤销入口还原原尺寸、约束、链接和几何。通过检查同一草图及当时状态限制撤销范围。 |
| 装配体自身二维草图 | 单配置临时装配体的两个圆改为 Ø12.5 mm，两项原生直径均加入同一链接组。 |

零件回归和装配体测试均以退出码 0 完成。可用 `verify/Invoke-CircleDiameterVerification.ps1 -Mode Regression` 和 `-Mode AssemblySmoke` 重跑。

## 实现验证要点

SOLIDWORKS 在 `EditRebuild3` 后可能退出草图编辑。宏只会重新进入本次操作的原草图，然后核对结果。等径组依据当前草图归属及草图内实体 ID 识别。还原前先恢复原驱动值并求解，再移除本批新增的尺寸标注，随后核对原有尺寸名称和几何。

本机的 Ctrl+Z 实测按 SOLIDWORKS 自身记录逐步回退。宏提供独立的 **撤销最近一批** 方法用于恢复整个最近批次。

## 交互验收状态

Windows 锁屏阻止了最后一次原生宏编辑器保存和工具栏配置。当前提供与回归源码一致的 `BatchCircleDiameter.swb`，可从 SOLIDWORKS 的宏运行菜单加载。最终 `.swp`、按钮绑定、交互取消以及跨两次按钮调用的撤销仍待实测。
