# SOLIDWORKS 草图快捷工具

## 新电脑安装 1.2 版

1. 把 `SOLIDWORKS草图快捷工具_1.2_新电脑安装包.zip` 发到新电脑，完整解压到 D 盘或其他非 C 盘目录。
2. 双击 **Install.cmd**，在 Windows 管理员确认窗口点 **是**。脚本自动寻找本机已安装的 SOLIDWORKS，使用本机接口编译并安装到 `D:\SolidWorksSketchTools\1.2.1.0`，启用当前用户的启动加载。
3. 保存工作后启动或重启 SOLIDWORKS。可在 **工具 → 加载项** 确认 **草图快捷工具** 已启用。

安装包附有源码和离线构建脚本。实测环境为 64 位 Windows、SOLIDWORKS 2026 SP0.0 和 .NET Framework 4.8。其他版本安装目录会被自动识别并重新编译，兼容性需在对应电脑验证。若有多个 SOLIDWORKS 版本，默认选择注册的最高版本。可用下方参数指定目录。

```powershell
.\Setup.ps1 -SolidWorksPath 'D:\SOLIDWORKS Corp\SOLIDWORKS' -InstallRoot 'E:\SolidWorksSketchTools'
```

安装失败时，查看解压目录的 `Setup.log`。没有 D 盘时，通过 `-InstallRoot` 指定另一块盘。更新时插件会使用新的版本目录。

## 零件文件文字批注

打开 `.SLDPRT`，退出草图编辑，选中一个面、边或顶点。点 **工具 → 零件批注 → 添加文字批注**，输入中文或多行文字后点 **添加**。插件会激活注解视图并把文字放到实体轮廓外侧，稍微缩小视图以方便查看。保存零件即可保留文字和引线。

可在 **视图 → 工具栏 → 零件批注** 显示按钮，也可在 **工具 → 自定义 → 键盘** 中给 **添加文字批注** 绑定自选快捷键。双击原生注释可继续编辑文字。

## 菜单变灰时

先在图形区选中目标，再打开工具菜单。三个命令会按当前操作状态自动启用。

| 想做的操作 | 启用前的状态 |
| --- | --- |
| 零件文字批注 | 单独打开零件，退出草图编辑，选中一个面、边或顶点。 |
| 装配体文字批注 | 在装配体层级，退出零件或草图编辑，选中一个可见、已解析的零件或其面、边、顶点。 |
| 选中欠定义圆 | 正在编辑零件或装配体自身的二维草图。 |

例如，装配体窗口里没有选中对象、也没有编辑草图时，三个命令都会变灰。

## 草图选圆

打开零件或装配体自身的二维草图，按在 SOLIDWORKS 中绑定的快捷键，或点击 **草图快捷工具** 工具栏上的蓝色圆形按钮。当前电脑已经绑定 `Ctrl+Alt+Shift+O` 并启用工具栏。新电脑可通过 **视图 → 工具栏 → 草图快捷工具** 显示按钮。

命令会高亮欠定义的整圆，包括构造圆和已有直径但圆心位置仍欠定义的圆。状态栏显示选中的数量。

## 装配体文字批注

1. 在装配体窗口选中一个零件。可从特征树选零件，也可在图形区选零件的面、边或顶点。
2. 点 **工具 → 装配体批注 → 添加零件批注**，输入文字并点 **添加**。也可从 **视图 → 工具栏 → 装配体批注** 显示按钮。
3. 保存装配体。文字和引线作为 SOLIDWORKS 原生注释存入装配体，对应到实际选中的零件实例。

添加前请退出零件或草图编辑，并确认目标零件可见且已解析。命令支持中文和多行输入。选面、边或顶点时，引线使用该几何位置。从特征树选零件时，插件按当前视角选择该零件的表面。

## 安装到另一台电脑

1. 解压整个目录。`dist` 里包含 DLL 和命令图标。
2. 用管理员身份启动 **64 位 Windows PowerShell**，进入解压目录，运行以下命令。`-SolidWorksPath` 指向新电脑的 SOLIDWORKS 安装目录。

   ```powershell
   .\Install.ps1 -SolidWorksPath 'D:\sw2026\sw\SOLIDWORKS'
   ```

3. 在 SOLIDWORKS 的 **工具 → 加载项** 中启用 **草图快捷工具**，并勾选启动加载。打开一个零件，再到 **工具 → 自定义 → 键盘** 搜索 **选中欠定义圆**，绑定 `Ctrl+Alt+O`。有冲突时使用 `Ctrl+Alt+Shift+O`，或继续用按钮。

升级时若旧版已加载，请保存工作后重启 SOLIDWORKS，以加载新版本。

如果安装脚本提示接口版本不一致，先用目标电脑安装目录重新编译，再安装。

```powershell
.\Build.ps1 -SolidWorksPath 'D:\sw2026\sw\SOLIDWORKS'
.\Install.ps1 -SolidWorksPath 'D:\sw2026\sw\SOLIDWORKS'
```

## 扩展命令

在 `SketchCommands.cs` 注册新命令并分配独立命令 ID。在 `SketchToolsAddin.cs` 提供命令入口，把具体操作放在单独的代码文件。升级沿用加载项标识和已发布命令 ID。命令组结构变化时，按 SOLIDWORKS 的命令组升级要求分配新的组 ID，并复验用户的快捷键。 [命令组接口](https://help.solidworks.com/2025/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.ICommandManager~CreateCommandGroup2.html)
