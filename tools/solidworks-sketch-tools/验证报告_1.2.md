# 1.2 版零件文字批注验证报告

2026 年 11 月 22 日，在 SOLIDWORKS Design Premium 2026 SP0.0（API 34.0.0）和 .NET Framework 4.8 中验证。升级沿用加载项标识和原有命令组，新增 **零件批注 → 添加文字批注**。

| 场景 | 验证结果 |
| --- | --- |
| 独立零件选择面、边、顶点 | 三种对象均可创建原生带引线文字批注。验证了引线持久引用与所选几何体一致。 |
| 中文及多行文字 | 逐条读取文字并核对一致。 |
| 保存、关闭及重开 SLDPRT | 三条文字和对应的面、边、顶点引线归属保持正确。 |
| 空白文本、无选择、多选 | 空白文本不创建注释，无选择或多选时命令禁用。 |
| 几何核对 | 添加批注前后零件实体包围盒一致。 |
| 装配体回归 | 两个相同零件的不同实例分别创建批注，保存重开后文字和实际实例归属一致，零件文档保存状态保持清洁。 |
| 选圆回归 | 自由圆、构造圆和已有直径的欠定义圆正确入选；无匹配与三维草图保留选择；装配体自身草图通过测试。 |
| 新机安装流程 | 在包含中文和空格的独立解压目录运行 Setup.ps1，通过注册表自动定位 SOLIDWORKS，调用本机编译器生成 DLL，管理员注册成功。最终修订版目录为 D:\SolidWorksSketchTools\1.2.1.0。 |
| 实际界面 | 从零件批注菜单实测取消和添加中文多行文字。可见性修订版自动激活注解视图并将文字放在实体外侧，独立测试窗口里两行文字和引线清楚可见，无需手动调整显示。 |
| 加载项生命周期 | 最终安装版在独立 SOLIDWORKS 进程中加载、卸载和重载成功，三个命令菜单各出现一次。 |

可运行 `Verify.ps1 -PartNote`、`Verify.ps1 -AssemblyNote` 和 `Verify.ps1` 重跑实机接口验收。测试脚本使用临时 CAD 文件。新电脑仍需实际安装与使用验收。

当前安装版本为 1.2.1.0。安装目录 DLL 的 SHA-256 为 `3C4D46D23FC83AB79E46A5B67EF920D3B7A44BBC9B6921E92687D18512A51AD7`，与发布包 `dist` 中的 DLL 一致。新机安装会重新编译，因此目标电脑的二进制哈希可能随构建时间变化。

2026 年 11 月 22 日补验了用户当前会话的菜单启用条件。在同一进程中新建临时模型，直接调用已加载插件的启用回调。零件批注无选择时为 0，选中面、边、顶点时分别为 1。装配体批注无选择时为 0，选中零件时为 1。零件和装配体自身二维草图中的选圆回调均为 1。上述用例随后完成文字、引线、保存重开和选圆测试，恢复了原活动文档及保存状态。

随后在用户当前的装配体窗口实点核对。选中一个可见零件面后，装配体批注命令立即启用并打开输入框，显示正确的零件实例。取消空输入框后保留选择，未在用户模型中创建批注。证据为 `D:\SolidWorksSketchToolsVerification\ActivationDiagnosis\ui\dialog-open.png`。
