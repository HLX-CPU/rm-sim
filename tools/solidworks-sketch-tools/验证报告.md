# 草图快捷工具验证报告

2026 年 11 月 20 日在本机 SOLIDWORKS Design Premium 2026 SP0.0（API 34.0.0）验证。加载项使用 .NET Framework 4.8 和安装目录自带的 SOLIDWORKS 接口构建为 x64 DLL。

## 已通过的验证

| 场景 | 实测结果 |
| --- | --- |
| 混合二维零件草图 | 选中自由整圆、构造圆和已有直径但圆心欠定义的圆，替换预先选中的直线。完全定义的圆、圆弧和直线保持未选中。 |
| 选择前后比较 | 草图更新标记、圆心、半径、直线端点、约束数量和已有直径值一致。 |
| 无目标与三维草图 | 空草图未产生选择。只有直线的草图和三维草图保留原选择。 |
| 装配体自身的二维草图 | 两个欠定义整圆均入选。 |
| 当前电脑实际快捷键 | `Ctrl+Alt+O` 已被 QQ 全局取色占用。SOLIDWORKS 已绑定 `Ctrl+Alt+Shift+O`，清除选择后实按选中 3 个目标圆，后台读取的实体 ID 为 `1:0:1`、`1:1:2`、`1:2:3`。 |
| 原生命令入口 | 原生菜单命令曾实点选中同样 3 个圆。清理旧会话的重复菜单后，启用 **视图 → 工具栏 → 草图快捷工具**。清空选择后实点蓝色圆形按钮，后台复核正好选中 3 个目标圆。 |
| 本机安装与加载 | 已注册 COM 和 SOLIDWORKS 加载项目录，修正版安装到 `D:\SolidWorksSketchTools\1.0.0.0`。 |
| 卸载与重新加载 | 初次验收发现 SOLIDWORKS SP0.0 在按运行时移除命令组后仍保留菜单项。修正版在独立新会话中实测加载、卸载、重载，菜单组数量依次为 1、0、1。 |

回归只使用临时文档。后台验证结束后恢复过原活动装配体，核对了原保存状态。旧 SOLIDWORKS 进程已缓存首个加载项 DLL，按键可在当前会话继续使用。修正版已注册，启动加载设置已启用。当前会话中修正版尚未接管，修正版与快捷键的组合尚未跨 SOLIDWORKS 启动实按。

## 复验

运行 `Build.ps1` 构建，再运行 `Verify.ps1` 复验核心命令。脚本会连接当前 SOLIDWORKS 会话，创建及关闭临时模型。当前用户的加载项启动设置已启用。

## 1.1 版装配体文字批注

- 使用同一个零件的两个装配体实例测试，按特征树零件和图形区面的选择创建中文原生注释。多行内容和可见引线均通过检查，引线指向实际选中的实例。
- 保存、关闭并重开临时装配体后，两个批注的文字、引线和实例归属均正确。引用零件文档的保存标志保持清洁。
- 未选零件和选中多个零件时，命令不可用。空白文本不创建注释。1.0 的选圆回归通过。
- 1.1 已安装注册到 `D:\SolidWorksSketchTools\1.1.0.0`，在新启动的 SOLIDWORKS 进程中核对到新命令已加载。可通过 `Verify.ps1 -AssemblyNote` 重跑装配体批注测试。
- 界面测试确认菜单可打开对话框、显示所选实例，取消后保持原选择且没有新增注释。用户反馈功能使用正常。完整的保存重开及引线归属由独立的实机 API 用例核对。
